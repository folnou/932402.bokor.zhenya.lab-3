# Лабораторная работа №3
Вариант: 6
Тема: «Любитель кино и сериалов» (Киноафиша и рейтинг)
Цветовая гамма: Чёрно-золотая 

## Выполненные требования

Flexbox: Реализована горизонтальная навигация (nav ul) и адаптивная сетка карточек фильмов (.cards). Внутри карточки использован Flex для выравнивания постера и текста.

CSS Grid: Галерея любимых режиссёров (.gallery) построена на двумерной сетке. На десктопе отображается в 2 колонки, на мобильном — в 1.

Адаптивность: Настроены медиа-запросы для трёх breakpoints:
- Мобильные : меню вертикальное, карточки и галерея в 1 колонку.
- Планшет : карточки в 2 колонки, галерея в 2 колонки.
- Десктоп : карточки в 3 колонки.

Семантика: 
- Карточки фильмов обёрнуты в <article>.
- Фотографии режиссёров оформлены через <figure> + <figcaption>.
- Боковой блок вынесен в <aside>.

Доступность и контрастность: 
- Контраст золотого текста на чёрном фоне > 4.5:1.
- Реализованы состояния :focus с видимым outline для клавиатурной навигации.
- У всех изображений прописаны атрибуты alt.

Интерактивность: Добавлены эффекты :hover (полупрозрачный оверлей на карточках, увеличение шрифта), :active (нажатие кнопки/карточки) и :visited для ссылок.

## Запуск
Откройте файл lab3.html в любом современном браузере. Для проверки адаптивности используйте инструменты разработчика (F12 → Toggle Device Toolbar).

## Проверка
HTML и CSS код проверен визуально и с помощью эмуляторов устройств на соответствие требованиям Flexbox, Grid и доступности. Горизонтальная прокрутка отсутствует на всех разрешениях.
